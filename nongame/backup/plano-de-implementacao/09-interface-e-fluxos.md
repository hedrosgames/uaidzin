# 09. Interface e Fluxos

## Fase 8

UI para administrar o RPG sem transformar o combate em menus.

## HUD da dungeon

- Vida (inferior esquerdo).
- Timer 10:00 (topo central).
- Skills + cooldown + flag auto (inferior central).
- Aviso inventário 80%/100%.
- Toast de loot.
- Dano flutuante placeholder.

## Cidade — telas

Personagem · Atributos · Equipamentos · Inventário · Skills · Especialização · Loja · Refinamento · Quests · Seleção de dungeon · Evolução · Reset · Opções.

Atalhos: I, C, K, J, M, Esc.

## Fluxos obrigatórios

1. Primeira entrada (criar personagem → tutorial → D1).
2. Morte (recursos mantidos → cidade).
3. Conclusão por tempo (resumo → cidade).
4. Level up (HUD; distribuir depois).
5. Loot / inventário cheio.
6. Evolução (Sábio).
7. Reset (Sábio + confirmação de custo).

## Tema

Dark técnico, acento âmbar, coerente com o GDD visual.

## Validação

Todos os sistemas acessíveis sem debug panel. Fluxo de morte e de 10 min completos pela UI.

## Saída

Jogo jogável de ponta a ponta pela interface.
