# UAIDZIN — material não runtime

Esta pasta concentra documentação, fontes, ferramentas de arquivo e assets que não são consumidos pelo jogo.

- `game/` na raiz: runtime Vite/Three.js.
- `visual/telas/`: wire e protótipos que o Vite publica.
- `docs/project/`: decisões, planos, inventários e checklist.
- `gdd/`: capítulos do GDD, builder e diagrama visual.
- `assets/`: fontes do Drive, clips sem uso e modelos candidatos.
- `game/`: documentação e fontes do pipeline de assets.
- `backup/`: histórico ainda útil.
